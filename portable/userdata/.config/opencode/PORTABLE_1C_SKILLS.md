# Совместимость путей portable-навыков 1С

Набор `cc-1c-skills` включён без изменений и загружается из переносимого каталога OpenCode. В исходных примерах upstream пути к вспомогательным файлам начинаются с `.opencode/skills/`, поскольку обычная установка помещает навыки в каталог проекта.

В этой portable-сборке при выполнении таких команд заменяй префикс `.opencode/skills/` на абсолютный каталог из переменной окружения `OPENCODE_1C_SKILLS_DIR`. В PowerShell используй `$env:OPENCODE_1C_SKILLS_DIR`; например, `.opencode/skills/epf-init/scripts/init.ps1` соответствует `Join-Path $env:OPENCODE_1C_SKILLS_DIR 'epf-init/scripts/init.ps1'`.

Не изменяй и не копируй upstream-навыки в проект только ради исправления пути. Рабочим каталогом для создаваемых и изменяемых файлов остаётся открытый пользователем проект.

Для `web-test` не утверждай, что `npm install` загружает браузер. В каталоге `web-test/scripts` сначала выполни `npm install`, затем отдельную команду `npx playwright install chromium`.

Навык `web-publish` отключён политикой portable-конфигурации. Не обходи запрет и не запускай его скрипты: их автоматическая установка получает изменяемую сборку Apache без закреплённой контрольной суммы. Для публикации сообщи пользователю, что нужен вручную установленный и проверенный Apache с явным `-ApachePath`.
