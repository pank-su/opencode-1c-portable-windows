# OpenCode 1C Portable для Windows x64

Сборка содержит официальный `opencode.exe`, переносимые настройки и полный включённый набор из 79 навыков разработки 1С; `web-publish` отключён по умолчанию.

## Запуск

Откройте PowerShell в каталоге проекта 1С и вызовите launcher по абсолютному пути:

```powershell
& "D:\Tools\OpenCode-1C-Portable-Windows-x64\opencode.cmd"
```

Текущий каталог PowerShell останется рабочим каталогом OpenCode. Аргументы CLI передаются напрямую:

```powershell
& "D:\Tools\OpenCode-1C-Portable-Windows-x64\opencode.cmd" run "Проверь модули 1С"
```

При первом запуске появится запрос API-ключа OpenCode Go. Ввод скрыт. Ключ хранится только в `userdata\.local\share\opencode\auth.json` рядом с программой.

Для повторной настройки ключа запустите:

```powershell
& ".\setup-key.cmd"
```

Для проверки установки:

```powershell
& ".\check.cmd"
```

## Что настроено

- модель: `opencode-go/gpt-5.6-luna`;
- автообновление отключено;
- конфигурация, авторизация, кэш и история находятся в `userdata`;
- 79 навыков 1С находятся в `userdata\.config\opencode\skills`.

OpenCode видит навыки автоматически. Их можно вызвать естественным запросом или явно, например: `Загрузи навык epf-init и создай внешнюю обработку`.

Набор взят без изменений из OpenCode-ветки [Nikolay-Shirokov/cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills/tree/port-opencode) (MIT), commit `05b3b3a58700f337a8b4e5c9e0e23f9bc0d8fdd0`. Источник, лицензия и SHA-256 manifest всех 341 файлов находятся в `userdata\.config\opencode\third-party\cc-1c-skills`.

Upstream-примеры используют проектный путь `.opencode/skills/`. Portable-конфигурация автоматически указывает OpenCode заменять этот префикс на каталог из `OPENCODE_1C_SKILLS_DIR`, не копируя и не изменяя навыки.

Базовые требования: Windows с PowerShell 5.1+; 1С:Предприятие 8.3 для сборки/разборки и работы с базами; Node.js 18+ для `/web-test`. В его каталоге `scripts` выполните `npm install` для пакетов, а затем отдельно `npx playwright install chromium` для загрузки браузера. Для записи видео дополнительно нужен `ffmpeg`; опциональная TTS-озвучка может требовать отдельный API-ключ провайдера, который не записывается `setup-key.ps1`. Основные команды OpenCode-ветки используют PowerShell, но в архиве также есть Python-варианты вспомогательных скриптов: при ручном вызове им нужны Python 3 и `lxml`, а `/img-grid` требует Pillow. Они не входят в архив; установка: `py -m pip install lxml Pillow`.

## Безопасность

Команды навыков могут запускать PowerShell, изменять проект и скачивать внешние инструменты. OpenCode запрашивает подтверждение перед каждым shell-запуском; проверяйте команду и источник загрузки перед разрешением.

`web-publish` находится в точной upstream-копии, но отключён по умолчанию: встроенная установка скачивает изменяемую сборку Apache без закреплённого SHA-256 и запускает её. Для безопасной работы установите проверенный Apache вручную и используйте `-ApachePath`; меняйте запрет только после собственного аудита.

Не публикуйте `userdata\.local\share\opencode\auth.json`. Удаление `userdata` сбрасывает локальную авторизацию, настройки, кэш и историю.

`setup-key.ps1` записывает ключ атомарно и применяет ACL только для текущего пользователя Windows. Требуется NTFS; на FAT/exFAT и некоторых сетевых или синхронизируемых томах ACL может быть недоступен. В этом случае скрипт завершится с ошибкой и не оставит ключ в незащищённом файле.

Бинарные файлы 1С (`.cf`, `.cfe`, `.dt`, `.epf`, `.erf`) нельзя безопасно редактировать как текст. Используйте выгруженные исходники конфигуратора/EDT либо проект OneScript.
